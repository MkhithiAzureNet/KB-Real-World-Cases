# Security Automation Scripts

## External Document Triage v1.2

**Script:** [SEC-001-External-Document-Triage-v1.2.ps1](./SEC-001-External-Document-Triage-v1.2.ps1)

Performs static triage of an Office document or PDF: records metadata and SHA-256, checks supported document structures, and can request a Microsoft Defender scan.

### Run

```powershell
.\SEC-001-External-Document-Triage-v1.2.ps1
```
